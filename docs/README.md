# Manual público del taller

`index.html` es el manual completo, paso por paso: instalación, los cuatro
bloques de la sesión con sus comandos, ejercicios con respuesta y la ruta de
continuación. Es un archivo autónomo, sin servidor ni dependencias.

Los participantes lo siguen durante la sesión: cada bloque de comandos tiene
botón de copiar, y el armador del paso 2 genera el encargo listo para pegar.

## Publicar con GitHub Pages

*Settings* → *Pages* → *Source: Deploy from a branch* → rama `main`, carpeta
`/docs`. Queda en:

```
https://ngzeggers.github.io/taller_instalacion/
```

## Imprimir

Tiene estilos de impresión: se despliegan las pestañas y los desplegables, y
se ocultan los botones de copiar. *Imprimir* → *Guardar como PDF* produce el
manual completo para la coordinación.
